## QR Code Generator

A simple QR Code Generator built using Python.

### Features
- Generates QR codes from text or website links.
- Saves QR codes as PNG images.
- Allows users to choose the file name.

### Technologies Used
- Python
- qrcode library

### How to Run
Install the required library:

    pip install "qrcode[pil]"

Run the program:

    python qr_generator.py
